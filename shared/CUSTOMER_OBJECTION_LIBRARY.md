# Customer Objection Library

Used by: Sales Rep, Follow-Up.

| Objection | Response approach |
|-----------|-------------------|
| Price too high | Value recap + ROI; escalate discount |
| Need to think | Clarify decision process + timeline |
| Using competitor | Differentiation from KB; no competitor bashing |
| No budget | Qualify timing; MEDDIC metrics |
| Need approval | Identify economic buyer; multi-thread |

Ground responses in CRM context. Escalate pricing per ESCALATION.md.

```yaml
playbook_id: objection_library
escalate_on: [pricing, legal, contract]
```
