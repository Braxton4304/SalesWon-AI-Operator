# Discovery Playbook

Implements shared sales knowledge for discovery phase. Used by: Sales Rep, Account Research, Sales Manager.

## SPIN Framework

- **Situation** — Current state, tools, team structure
- **Problem** — Pain points, cost of status quo
- **Implication** — Consequences of not solving
- **Need-payoff** — Value of solving

## CRM Documentation

Log discovery in opportunity notes and activities. Required: contact roles, pain summary, next step.

## Discovery Questions (Examples)

- What triggered this evaluation now?
- Who else is affected by this problem?
- What happens if this isn't solved this quarter?
