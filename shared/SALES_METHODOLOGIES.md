# Sales Methodologies

Reusable methodology frameworks for qualification and deal progression.

## Frameworks (TBD Content)

### MEDDIC

- **Metrics** — Quantified customer value
- **Economic Buyer** — Budget authority
- **Decision Criteria** — Evaluation process
- **Decision Process** — Steps to purchase
- **Identify Pain** — Compelling event
- **Champion** — Internal advocate

### SPIN

- **Situation** — Current state questions
- **Problem** — Pain discovery
- **Implication** — Consequence of inaction
- **Need-payoff** — Value of solution

### BANT (Legacy Reference)

- Budget, Authority, Need, Timeline — use for initial screening only
