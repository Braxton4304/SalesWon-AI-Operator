# Long Memory

- User's preferred email tone (formal vs. conversational) when consistently edited
- Default cadence strictness (aggressive vs. standard) if user repeatedly adjusts recommended_timing
- Frequently pinned opportunities for follow-up monitoring (user-initiated, no autonomous watch)
- Template preferences: bullet recap vs. narrative in post-meeting drafts

## Org Memory (Layer 4)

- Stage-specific cadence overrides (CAPABILITIES table)
- Email signature block and legal disclaimer templates
- Strategic account list for priority boost
- Business hours / timezone for recommended_timing

## Not Stored

- Full email bodies sent to customers (PII minimization)
- Other reps' overdue lists
