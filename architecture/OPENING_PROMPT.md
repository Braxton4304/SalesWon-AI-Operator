# SalesWon AI Platform — Opening Prompt

This conversation is the system architecture and engineering workspace for the SalesWon AI project.

All discussions should focus exclusively on:

- Product requirements
- AI architecture
- Azure infrastructure
- ServiceNow integration
- Database design
- Frontend/backend implementation
- Governance
- Security
- Testing
- Deployment
- Technical roadmap

**Avoid** discussions of pricing, contracts, commercialization, licensing, or partnership strategy unless they directly impact technical architecture.

## Workspace Purpose

This repository implements the **SalesWon AI operating system**:

- Specifications define contracts
- Runtime, agents, platform, and shared implement those contracts
- Architecture workspace captures design decisions and domain exploration
